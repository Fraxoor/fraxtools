## 🚀 Overview

**FRAX.TOOLS** is a suite of modern, zero-dependency browser utilities designed to solve everyday engineering, networking, and productivity tasks instantly. Everything runs entirely inside your browser using Vanilla JavaScript—no external servers, no tracking, and complete data privacy.

---

## 🧰 Tools Included

FRAX.TOOLS provides a curated set of powerful utilities across multiple categories:

| Tool | Category | Description |
| :--- | :--- | :--- |
| **JSON X-Ray** (`json`) | Developer | Inspect, format, validate, and explore JSON structures with interactive tree inspection. |
| **Header Detective** (`headers`) | Developer | Inspect HTTP response headers, understand their purpose, and check for missing security headers. |
| **Regex Playground** (`regex`) | Developer | Test JavaScript regular expressions against sample text and inspect matches and capture groups. |
| **SQL Anatomy** (`sql`) | Developer | Break down SQL queries into readable clauses and inspect their structure. |
| **Subnet Visualizer** (`subnet`) | System | Calculate IPv4 network addresses, broadcast addresses, and usable host ranges from CIDR. |
| **Storage Map** (`storage`) | System | Visualize the size of files in a selected local folder (all processing happens in-browser). |
| **Cron Visualizer** (`cron`) | Productivity | Parse standard five-field cron expressions and preview upcoming execution times in your local timezone. |
| **Image Forensics Lite** (`image`) | File | Inspect local image properties (dimensions, format, metadata) without server uploads. |
| **Contrast Lab** (`contrast`) | Productivity | Check WCAG color contrast and accessibility ratios with foreground/background previews. |
| **Text Surgery** (`diff`) | Developer | Compare two text blocks line by line and inspect added, removed, and unchanged content. |

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Clean, responsive, modern dark-themed user interface.
- **Vanilla JavaScript (ES6+)**: Zero framework overhead, highly optimized performance.
- **Client-Side Storage & Processing**: All data stays locally in your browser memory or local storage.

## 🏁 Getting Started

Since FRAX.TOOLS is 100% client-side, you can run it instantly without complex build steps or backend servers.

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/fraxoor/fraxtools.git
   cd fraxtools
   ```

2. Open the application using any static web server (e.g. `npx serve`, `python3 -m http.server`, or Live Server in VS Code).
